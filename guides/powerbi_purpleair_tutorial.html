Power BI Air Quality Analysis

Converting Python Data Analysis to Interactive Power BI Reports

0Setup: Import Data into Power BI Desktop

Option A: Excel File Import

  1. Open Power BI Desktop
  2. Go to Get Data → Excel
  3. Select your 2025_24hour.xlsx file
  4. In Navigator, choose the sheet containing the five raw columns:
    • humidity
    • temperature
    • pm2.5_atm
    • datetime
    • date
  5. Click Transform Data to open Power Query editor

Option B: Live API Data Download

For real-time data from PurpleAir sensors:

  1. Create a developer account at https://develop.purpleair.com/sign-in
  2. Click Create Key → Read. Copy the 36-character key.
  3. Open Power BI Desktop
  4. Go to Get Data → Blank Query
  5. In the Power Query editor, go to Home → Advanced Editor
  6. Replace the default code with the PurpleAir API downloader:
// --- Parameters ---
let
    ApiKey   = "API-KEY",
    SensorId = 123456,
    Year     = 2025,
// --- Build epoch start & end timestamps (UTC) ---
    EpochStart =
        Number.Round(
            Duration.TotalSeconds(
                #datetimezone(Year,     1, 1, 0, 0, 0, 0, 0)
              - #datetimezone(1970,    1, 1, 0, 0, 0, 0, 0)
            ), 0),
    EpochEnd   =
        Number.Round(
            Duration.TotalSeconds(
                #datetimezone(Year + 1, 1, 1, 0, 0, 0, 0, 0)
              - #datetimezone(1970,    1, 1, 0, 0, 0, 0, 0)
            ), 0),
// --- Assemble request ---
    BaseUrl   = "https://api.purpleair.com/v1/sensors/"
                & Number.ToText(SensorId) & "/history",
    Source    = Json.Document(
                    Web.Contents(
                        BaseUrl,
                        [
                            Headers = [#"X-API-Key" = ApiKey],
                            Query   = [
                                start_timestamp = Number.ToText(EpochStart),
                                end_timestamp   = Number.ToText(EpochEnd),
                                average         = "1440",               // 24 h bins
                                fields          = "pm2.5_atm,temperature,humidity"
                            ]
                        ]
                    )
                ),
// --- Turn JSON payload into a table ---
    RawTable  = Table.FromRows(Source[data], Source[fields]),
// --- Clean-up & enrich ---
    #"Changed Type" = Table.TransformColumnTypes(
                         RawTable,
                         {
                             {"time_stamp", Int64.Type},
                             {"pm2.5_atm",  type number},
                             {"temperature", type number},
                             {"humidity",   type number}
                         }
                     ),
    #"Add datetime" = Table.AddColumn(
                         #"Changed Type", "datetime",
                         each #datetime(1970,1,1,0,0,0)
                              + #duration(0,0,0,[time_stamp]),
                         type datetimezone
                     ),
    #"Add date"     = Table.AddColumn(
                         #"Add datetime", "date",
                         each Date.From([datetime]),
                         type date
                     ),
    #"Removed Columns" = Table.RemoveColumns(#"Add date", {"time_stamp"})
in
    #"Removed Columns"
Before using the API code:
  • Replace "API-KEY" with your actual PurpleAir API key
  • Replace 123456 with your target sensor ID
  • Adjust the Year parameter as needed
  • Set credential to Anonymous when prompted
You should now see a query with the five columns (humidity, temperature, pm2.5_atm, datetime, date) either from Excel or the API. The data processing steps remain the same for both methods.

1Power Query (M) — Data Preprocessing

1.1 Rename Columns and Set Data Types

Column Data Type
humidity, temperature, pm2.5_atm Decimal Number
datetime Date/Time/Timezone (keeps "+00:00" UTC offset)
date Date
Home → Transform → Detect Data Type works well for automatic type detection.

1.2 Add Engineered Columns

Use Add Column → Custom Column unless noted otherwise:

Python Field M Expression Notes
hour Date.Hour([datetime]) Add Column → Time → Hour → Hour
day_of_week Date.DayOfWeek([datetime], Day.Monday) Monday = 0, ..., Sunday = 6
day_name Date.ToText([datetime],"dddd") Full day name
month Date.Month([datetime]) Month number
week_of_year Date.WeekOfYear([datetime], Day.Monday) Week number

Time Period Classification

if [hour] < 6 then "Night" else if [hour] < 12 then "Morning" else if [hour] < 18 then "Afternoon" else "Evening"

AQI Category Classification

let pm=[pm2.5_atm] in if pm <= 12 then "Good" else if pm <= 35.4 then "Moderate" else if pm <= 55.4 then "Unhealthy for Sensitive" else if pm <= 150.4 then "Unhealthy" else if pm <= 250.4 then "Very Unhealthy" else "Hazardous"

Data Quality Flags

if [temperature] < -40 or [temperature] > 120 then true else false

Repeat similar logic for humidity and pm2.5 bounds.

Keep the flags but don't remove outliers here—use slicers or filters in the report so you can toggle them on/off.

2DAX — Rolling Averages & Statistics

Create these in Model view → New measure (or New column where noted).

2.1 Calendar Table

Required for DAX time functions:

Date = ADDCOLUMNS ( CALENDAR ( MIN ( Air[date] ), MAX ( Air[date] ) ), "Year", YEAR ( [Date] ), "Month", FORMAT ( [Date], "mmm" ), "Day", WEEKDAY ( [Date], 2 ) )
In Model view → Manage relationships → link Air[date] ↔ Date[Date] (Many-to-1, single direction).

2.2 Rolling Averages (Measures)

3-Hour Rolling Average

PM25 Rolling 3 h := VAR CurrentTime = MAX ( Air[datetime] ) RETURN CALCULATE ( AVERAGE ( Air[pm2.5_atm] ), FILTER ( ALL ( Air ), Air[datetime] > CurrentTime - TIME ( 3, 0, 0 ) && Air[datetime] <= CurrentTime ) )

24-Hour Rolling Average

PM25 Rolling 24 h := CALCULATE ( [PM25 μg m3], -- or AVERAGE ( Air[pm2.5_atm] ) DATESINPERIOD ( Date[DateTime], -- create a DateTime column in Date table MAX ( Air[datetime] ), -24, HOUR ) )

2.3 Basic Statistical Measures

PM25 Avg := AVERAGE ( Air[pm2.5_atm] ) PM25 Max := MAX ( Air[pm2.5_atm] ) PM25 Min := MIN ( Air[pm2.5_atm] ) Humidity Avg := AVERAGE ( Air[humidity] ) Temperature Avg := AVERAGE ( Air[temperature] )
